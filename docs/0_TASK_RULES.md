# Task Guidance Rules

This are some rules for guidance you:

1. Read all files inside `docs/` dir before doing anything in the task
2. If the task ended sucessfully create a new md file inside this dir and improve this file with more rules related to WHAT to do in a task execution
3. The new md file inside `docs` dir should be named `<task_number>_<task_secription>.md`
4. After improving docs you should commit and push
